# ZUOSEN · 国内合同与外贸 PI 工作台

纯静态 PI 工作台，支持电脑和手机制作并保存单据。GitHub Pages 地址：[在线制作 PI](https://q919237359-ops.github.io/zuosen-pi-studio/)。

## 本地打开

直接双击 `index.html`，在浏览器中打开即可。也可以进入本目录后运行：

```bash
python3 -m http.server 8080
```

浏览器访问 `http://localhost:8080`。关闭终端服务后，本地网址停止访问。

不需要安装依赖或运行构建；页面不依赖 CDN、API 或服务器。建议固定使用同一个浏览器和打开方式，避免把不同来源下的本地数据误认为丢失。

## 使用流程

1. 选择「国内合同」或「外贸 PI」，然后选择开单抬头；在「抬头与公章」中填写各公司的联系、收款资料和对应章图。
2. 维护客户库、产品库，制作 PI 时直接选用，也可按单修改。
3. 填写 PI 编号、日期、产品、数量、单价和交易条款，检查金额与预览。
4. 点「保存到本地」直接下载含公章的 A4 PDF；也可保存到历史记录、导出 Excel 或打印。
5. 定期导出 JSON 备份；换设备或浏览器时导入恢复。

Excel 导出为可用电子表格软件打开的真实 `.xlsx` 文件，包含金额计算公式。外贸预览、PDF 与 Excel 均按提供的 ZSDP26100816.xls 首张 PI 表格重建，包含 ZUOSEN Logo、ISO 标识、授权签字与椭圆公司公章。商品和费用行按实际内容增加；金额大写按总额自动生成，修正原件旧订单大写与数字不一致的问题。

「保存到本地」直接在浏览器生成并下载当前 PI 的 A4 PDF，不需要打开系统打印，也不上传单据。页面按表格行分页，并在后续页重复抬头与产品列名；公章和签字保留为同一完整行。每页单独生成画布，避免长单据超过手机画布高度；单个异常长行会缩小以完整保留内容。PDF 将文字和原图一同保存为高分辨率页面图像；需要编辑单据时使用 Excel 或 JSON。浏览器「打印」仍可作为另一种 PDF 保存方式，纸张选 **A4**，关闭浏览器自带页眉和页脚。

已验证金额计算、Excel 文件结构、公司设置、客户/产品库、历史记录、刷新恢复、JSON 备份恢复，以及示例 A4 单页 PDF。手机端完成 Chromium 浏览器的 320/375/390px 竖屏、812×375 触屏横屏、820px 平板和 1440px 桌面测试，包含合成触屏滑动、删除撤销、原尺寸预览、文件下载回退及软键盘尺寸模拟。尚未使用实体 iPhone/Android 验证原生系统分享和打印界面。

## 添加到手机桌面与离线开单

手机页面顶部「添加到手机桌面」卡片，或「更多」菜单中的同名入口，可打开安装窗口或对应浏览器的操作说明。安装图标使用项目原版 ZUOSEN Logo，名称为「ZUOSEN PI」。

- iPhone：用 Safari 打开线上网址，点分享 → 添加到主屏幕 → 添加；如显示「作为网页 App 打开」，保持开启。
- Android：点击页面安装入口，或浏览器菜单 → 安装并创建快捷方式 → 安装（部分版本叫「安装应用」或「添加到主屏幕」）。
- 微信：先选择在浏览器打开；没有此选项时，复制链接到 Safari / Chrome，再完成添加。

首次从桌面图标打开时请保持联网，等待「离线资源已准备好」。完整离线包包含编辑程序、样式、全部内置 Logo/公章及 PDF 组件。准备完成后可断网打开、创建或修改国内合同/外贸 PI、切换抬头、公章、保存草稿/历史并导出 PDF、Excel 和 JSON。浏览器不支持安装时仍可正常在线使用；网站无法代替用户完成手机系统的安装确认。

业务资料仍保存在当前浏览器或桌面应用的数据空间，不会自动同步；需要迁移时使用全部 JSON 备份。离线资源需要首次联网准备，清除网站数据或浏览器回收缓存后需重新联网准备。

后续发布修改运行文件时，同步递增 `sw.js` 与 `offline.js` 的 BUILD 及 HTML 引用版本。新版本整包缓存成功后，等待旧页面关闭才接管；用户保存资料、关闭所有工作台页面后重新打开即可更新，不会在编辑时自动刷新。离线缓存只包含白名单静态资源，不缓存业务数据或其他网站内容。

安装流程依据：[Apple 添加到主屏幕](https://support.apple.com/zh-cn/guide/iphone/iphea86e5236/ios)、[Chrome 桌面快捷方式](https://support.google.com/chrome/answer/15085120?co=GENIE.Platform%3DAndroid&hl=zh-Hans)、[MDN 安装要求](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)。

## 国内合同与公司抬头

国内采用提供的中文供货合同版式，人民币计价，包含双方资料、产品明细、人民币大写、合同条款、签章与人民币收款资料。默认提供「深圳市佐森科技有限公司」和「广东卓信液压科技有限公司」，各自对应用户提供的红色公章；外贸保留原有英文 PI 和椭圆公章。

「管理抬头与公章」支持新增、改名、修改各公司资料和账户、选择预设章、上传替换公章或设为不盖章，也可设定国内/外贸默认抬头。保存只更新公司资料；「保存并用于当前单据」才会替换当前单据资料。已存历史保留保存时的抬头、账户与章图。

国内与外贸草稿分别自动保存，切换时保留各自客户、数量、价格和条款。国内收款账户、税号和联系人由使用者填写，不会套用外贸账户。新增公司、公章、历史与双草稿均随全部 JSON 备份迁移；既有浏览器资料会自动兼容。

网站使用项目中的 ZUOSEN 原版 Logo。手机和桌面布局完成响应式及 Web Design Guidelines 检查，含表单行内错误、键盘焦点、触摸按钮尺寸、减少动态效果、未保存设置提示和长内容防溢出。

## 手机尺寸演示

在电脑上打开 `mobile-demo.html`，即可在手机外框中操作完整网站，支持 375×812、390×844、430×932 三档尺寸。演示页会适应电脑窗口大小，内部仍保持所选手机视口；与同一来源的桌面版共用本机资料，编辑会自动保存。正式工作台不显示演示入口。

客户下拉框已提供虚构的 `ATLAS HOME SUPPLIES (DEMO)`，选择后自动带入联系人 Alex Morgan、德国示例地址和 example.com 邮箱。该客户仅初始化一次，删除后不会在每次刷新时重复添加。

产品库和产品下拉框已提供 `ARL1-16-FR01S-10` 变量柱塞泵，型号与规格核对自用户图册 `知识库文件/ZUOSEN Catalog.pdf` 第 25 页（印刷页 C01/C02）：排量 16.3 cm³/rev，压力最高 7 MPa，转速最高 1800 r/min，法兰安装、顺时针旋转、压力补偿控制、右侧吸油口。原图册和产品图片没有加入网站。单价默认 0 并注明待确认，需填入真实报价后再使用；该示例只初始化一次，删除后刷新不会重复添加。演示按钮也使用此图册产品，买方与买方联系方式为虚构。

## 手机端使用

手机使用单独的操作布局：底部常驻「制作、客户、产品、历史、设置」，开单按「订单 → 产品 → 条款 → 预览」分步完成。金额和下一步按钮固定在下方；订单的地址与联系方式可按需展开。

- 预览页底部「保存到本地」直接下载 PDF；顶部「更多」也提供相同入口及新建 PI、保存历史、Excel、单据备份和全部备份恢复。
- 在预览页点「100% 阅读」可按原尺寸检查，左右滑动只发生在单据内部；点「适合屏幕」回到整页视图。
- 删除产品后可点「撤销」，恢复数量、单位、价格与备注。
- PDF 下载完成后，支持文件分享的手机浏览器会提供「分享 / 存到文件」按钮，可打开系统分享并保存到手机「文件」；下载文件也可在浏览器下载记录中找到。系统分享不可用时保留下载回退。「分享 Excel 文件」使用手机系统分享；不支持时下载 Excel。文件不会自动发送给客户。
- 公司和客户资料仍存本机；手机和电脑之间请用 JSON 备份迁移。

`127.0.0.1` 预览地址只用于运行本地服务的电脑；在外使用手机请打开上方 GitHub Pages 网址。

## 数据保存与备份

公司设置、客户库、产品库、PI 历史等数据保存在当前浏览器的 `localStorage` 中，不会自动同步到其他设备。清除网站数据、更换浏览器、使用隐私窗口或改变页面打开来源，可能无法读取原有数据。

JSON 备份用于跨设备恢复和保留完整工作数据；Excel/PDF 用于单据交付。备份可能包含客户及收款信息，请保存在自己的可靠位置。

用户提供的 Excel 附件作为原表模板，未上传到第三方服务。按本次要求内置原表的公司抬头、公开联系方式、收款资料和四张原始图片。仅在原先为空的资料中初始化；已填写的公司、银行和草稿不覆盖。旧买方、旧订单和原报价不作为默认内容；点击「填入图册产品示例」使用虚构客户和图册液压泵演示，单价待填写。

## 日常使用核对

- 公司设置、客户库、产品库、PI 编辑和历史记录可正常保存、读取。
- 数量、单价、费用与总额计算正确；货币、条款和收款资料经过人工确认。
- `.xlsx` 可正常打开，中文和金额无误；PDF 的 A4 预览完整。
- JSON 导出后能在另一个浏览器中恢复；导入行为与页面提示一致。
- 发布目录不包含原始订单文件、旧客户资料、个人备份或 QA 输出；模板公司资料、收款资料及公章按本次要求包含在网站中。

## 以后手动部署到 GitHub Pages

网站仓库为 `q919237359-ops/zuosen-pi-studio`。更新时上传本目录的网站文件，包含 `assets/`、`vendor/` 目录及根目录下的 `.nojekyll`。

在仓库 **Settings → Pages → Build and deployment** 中，Source 选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/ (root)`，保存即可。无需创建 Actions workflow。

部署后使用 GitHub 显示的网址访问。GitHub Pages 会发布网站文件，只上传程序、模板 assets、vendor 及演示数据；浏览器中的本地业务数据不会随网站文件自动上传。

## PDF 组件

直接保存 PDF 使用本地打包的 [html2canvas 1.4.1](https://github.com/niklasvh/html2canvas/releases/tag/v1.4.1) 和 [jsPDF 4.2.1](https://github.com/parallax/jsPDF)，均从各项目官方 npm 包提取，采用 MIT 许可，许可原文保存在 `vendor/`。第一次保存时按需从本站加载，运行时不依赖第三方 CDN。
