# ZUOSEN template artwork

Original company logo, ISO mark, authorized signature and international seal were extracted from the supplied PI template. The two domestic seal PNGs are the supplied original images, for 深圳市佐森科技有限公司 and 广东卓信液压科技有限公司. The domestic logo was extracted from the supplied supply-contract PDF. The square favicon comes from the existing project branding asset. Used at the owner’s request.

Only template artwork is included. Original order documents, old buyers, domestic bank accounts, contacts, and browser backups are not distributed here.

The 192/512 PNG app icons and 180 PNG Apple touch icon are size variants of the existing square ZUOSEN branding image, for home-screen installation.
